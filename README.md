# 🌐 Personal Portfolio Website

## 📖 Project Description

A personal portfolio website created to establish my professional online presence and showcase my journey as an aspiring software developer.

This project was developed as part of my **Web Development Internship**, providing an opportunity to apply my front-end development knowledge to a real-world website. It highlights my technical skills, projects, certifications, achievements, and academic background through a clean and interactive interface.

The website is designed to help recruiters, developers, and collaborators explore my work and connect with me.

## ⚙️ Getting Started

Want to explore or run this project on your local machine?

**Step 1: Clone the repository**

```bash
git clone https://github.com/Rashika-06/portfolio.git
```

**Step 2: Open the project directory**

```bash
cd portfolio
```

**Step 3: Run the website**

Open `index.html` in your preferred web browser.

No additional setup or dependencies are required.
